AURVIK — a travel poster for a place that isn't there: an aurora-lit fjord town in the far north, where a lighthouse carved from a single glacier spire glows through the night and the sky never goes dark. The poster is composed at build time from a generated scene, with the place name and the line "where the night glows" set in crisp type; the program itself only copies the finished 1024×1024 image to the output directory.

## Run it

```sh
python3 main.py
```
